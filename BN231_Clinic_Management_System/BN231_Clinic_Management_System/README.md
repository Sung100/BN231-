# Community Health Clinic Management System

Java 17 Swing application using MVC, `ArrayList`, object-file persistence, linear search and insertion sort.

## Run

1. Open this folder as a Maven project in IntelliJ IDEA, NetBeans or Eclipse.
2. Run `com.bn231.clinic.ClinicApplication`, or use `mvn compile exec:java`.
3. Run tests with `mvn test`.

Data is saved automatically to `data/clinic.dat`. IDs must be unique. Dates use `yyyy-MM-dd`; appointment times use `HH:mm`.
